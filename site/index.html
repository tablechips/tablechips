How it works

Three steps, and the deck stays real.

1

Open the table

The host turns on the hotspot and opens a table in TableChips. Pick the game and the starting stack.

2

Everyone scans the code

The camera opens the browser, and you're seated. Anyone with the app gets the app instead.

3

Play with real cards

TableChips keeps the chips. It never deals: you shuffle, you deal, you play as you always have.

Why this one

Every other chip app makes every guest install it. This one doesn't.

Guests install nothing

The host serves a web page. An iPhone and an Android at the same table both just open a browser.

No internet, ever

Everything runs on the host's hotspot. It works in a mountain hut, a campsite or a village with no signal.

Up to ten players

Each on their own device, each seeing their own stack in numbers big enough to read across the table.

Unlimited undo

A full log of every move. A wrong tap is a tap away from fixed, and you can always type the amount.

Built for a long night

Phones reconnect, seats are recoverable, and the table survives the host app being closed.

Questions

Before you ask.

Do I need internet?

No. The host phone creates its own Wi-Fi with the hotspot and everyone connects to it. No data leaves the table.

Can I play from an iPhone?

Yes, as a guest: scan the code and play from Safari. Hosting the table needs an Android phone.

Is this for gambling?

TableChips counts chips. It has no money, no payments and no accounts: what a chip is worth is up to the people at the table.

Does it deal the cards?

No, on purpose. You play with a real deck; the app only keeps the score.

Why isn't it on Google Play?

It's free software and doesn't depend on Google services, so it lives on F-Droid and GitHub first.
